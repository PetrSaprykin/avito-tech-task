# Система модерации объявлений Авито

Веб-приложение для модерации объявлений на платформе. Позволяет просматривать, фильтровать и обрабатывать объявления, а также отслеживать статистику работы модератора.

## Стек технологий

### Основные технологии

- **React 18**
- **TypeScript**
- **Vite**
- **React Router**

### UI и стили

- **Ant Design** - библиотека компонентов. Выбрал её т.к есть большая база компонентов и хорошая и понятная документация
- **CSS Modules** - использовал для изоляции стилей компонентов

### Работа с API

- **Axios** - для запросов к API. Для меня удобнее чем fetch и лучше обрабатывает ошибки

### Дополнительные библиотеки

- **Framer Motion** - использовал для создания для плавных анимаций переходов между страницами

- **NProgress** - прогресс-бар при загрузке, отображается вверху страницы

- **Recharts** - библиотека с графиками для страницы статистики. Выбрал потому что она проста в использовании

- **PapaParse** - библиотека для экпорта в CSV. Выбрал т.к. самая популярная библиотека для работы с CSV

- **jsPDF + jspdf-autotable** - библиотека для экспорта статистики в PDF, выбрал по той же причине, что и PapaParse

### Линтер и форматирование кода

- Настроен ESLint и Prettier для форматирования, чтобы всё выглядело в одном стиле

## Архитектура проекта

В архитекутуре использовал компонентный подход:

```

src/

|-- api/              # Длля работы с API

|-- components/       # Переиспользуемые компоненты

|-- contexts/         # React Context (для свитчера темы)

|-- hooks/           # Кастом хуки

|-- pages/           # Страницы приложения

|-- types/           # Типизация

|-- utils/           # Вспомогательные функции

└-- styles/          # Глобальные стили

```

Не стал использовать более сложные архитектуры, так как при масштабах проекта не считаю это необходимым.

Так же для удобства импортов для каждого компонента создавал index.ts с экспортом, а также настроил алиасы (@) для пути

## Реализованные фичи

### Основные функции

- Список объявлений с пагинацией (по 10 на странице)

- Фильтрация по статусу, категории, цене

- Поиск по названию с debounce (500мс)

- Сортировка по дате, цене, срочности

- Детальный просмотр объявления

- Модерация (одобрение/отклонение/доработка)

- История модерации каждого объявления

- Статистика модератора с графиками

- Фильтр по периодам на странице статистики

### Доп. фичи из ТЗ

- **Горячие клавиши:**

- `A` - одобрить объявление

- `D` - отклонить объявление

- `→ - следующее объявление

- `←` - предыдущее объявление

- `/` - фокус на поиск

- **Bulk-операции** - массовое одобрение/отклонение нескольких объявлений

- **URL-синхронизация фильтров** - можно поделиться ссылкой с нужными фильтрами

- **Тёмная тема** - переключатель светлой/тёмной темы

- **Экспорт данных** - статистику можно выгрузить в CSV или PDF

- **Анимации** - плавные переходы между страницами и появление карточек

- **Прогресс бар** - показывает что идёт загрузка при переходах

- **Отмена запросов** - используется AbortController чтобы отменять старые запросы

## Запуск проекта

### Требования

- Node.js 20+

### Локальный запуск

1. Склонируйте репозиторий:

```bash

git clone https://github.com/PetrSaprykin/avito-tech-task.git

cd avito-tech-task
```

2. Установите зависимости:

```bash

npm install

```

3. Запустите сервер в отдельном терминале:

```bash

cd server

npm install

npm start

```

Сервер должен запуститься на http://localhost:3000

Если не запустился, убейте процесс который занимает порт 3000, или используйте Docker-контейнер(инструкция ниже)

4. Запустите клиент:

```bash

npm run dev

```

Приложение станет доступно по адресу http://localhost:5173

### Запуск через Docker (удобнее)

1. Склонируйте репозиторий:

```bash

git clone https://github.com/PetrSaprykin/avito-tech-task.git

cd avito-tech-task

```

2. Проверьте что Docker Desktop запущен

3. Зайдите в корневую директорию проекта и в терминале выполните:

```bash

docker-compose up --build

```

3. Приложение будет доступно по адресу http://localhost:8080

4. Для остановки:

```bash

docker-compose down

```

Подробнее о запуске через Docker читайте в файле DOCKER.md

## Структура API

Приложение работает с локальным API сервером, у которого есть такие endpoints:

- `GET    /api/v1/ads` - список объявлений

- `GET    /api/v1/ads/{id}` - детали объявления

- `POST   /api/v1/ads/{id}/approve` - одобрить

- `POST   /api/v1/ads/{id}/reject` - отклонить

- `POST   /api/v1/ads/{id}/requset-changes` - отправить на доработку

- `GET    /api/v1/stats/summary` - общая статистика

- `GET    /api/v1/stats/chart/activity` - активность по дням

- `GET    /api/v1/stats/chart/decisions` - распределение решений

- `GET    /api/v1/stats/chart/categories` - распределение по категориям

- `GET    /api/v1/moderators/me` - информация о текущем модераторе

## Возможные проблемы

### Порт занят

Если при локальном запуске порт 5173 занят, измените его в `vite.config.ts`:

```typescript
export default defineConfig({
  server: {
    port: 8888, // любой свободный порт
  },
})
```

### Docker не запускается

Провертье что:

1. Docker Desktop запущен

2. В терминале работают команда `docker --version`

3. Порты 8080 и 3333 свободны

### API не отвечает (локальный запуск)

Проверьте что сервер запущен:

Из корневой директории:

```bash

cd server

npm start

```

Должно быть сообщение что сервер запустился на порту 3000.
